# 🐷 Astorias Jumping Pig

A fun and addictive browser-based game featuring a jumping pig! This project was born from a hilarious anecdote shared among friends, particularly with **Astorias**, who inspired the whole idea. What started as a joke has become a real game and a practical exercise to strengthen software development skills.

## 🎮 About the Game

Guide a brave pig through an endless series of obstacles by jumping at the right time! The game gets progressively harder as your score increases. How long can you keep the pig safe?

## ✨ Features

- 🐖 Adorable jumping pig character
- 🎯 Simple one-button controls (spacebar or click)
- 📊 Real-time score tracking
- 🚀 Progressive difficulty
- 🎨 Clean, minimalist design
- 📱 Works on desktop and mobile browsers

## 🚀 How to Play

1. **Open the game**: Simply open `index.html` in your web browser
2. **Start**: Click anywhere or press spacebar to start
3. **Jump**: Press spacebar or click/tap to make the pig jump
4. **Avoid obstacles**: Don't let the pig hit any obstacles
5. **Score points**: Each obstacle you pass increases your score
6. **Try again**: When you hit an obstacle, press spacebar or click to restart

## 🛠️ Setup

No installation required! Just clone and play:

```bash
git clone https://github.com/Lois-mttr/Astorias-Jumping-Pig-beta-.git
cd Astorias-Jumping-Pig-beta-
```

Then open `index.html` in your favorite web browser.

## 🎯 Technical Details

- **Frontend**: Pure HTML5, CSS3, and JavaScript
- **No dependencies**: Runs entirely in the browser
- **Canvas-based rendering**: Smooth 60 FPS gameplay
- **Responsive design**: Adapts to different screen sizes
