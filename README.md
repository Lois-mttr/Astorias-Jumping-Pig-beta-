# 🐷 Astorias’ Jumping Pig

## 🌱 About the Project | Sobre el Proyecto

### 🇪🇸 Español
Este proyecto es un juego inspirado en una anécdota divertida compartida con amigos, en particular con *Astorias*, quien dio origen a la idea. Presenta a un cerdito que salta y funciona como un ejercicio práctico para fortalecer habilidades en desarrollo de software.  
El proyecto se encuentra en constante evolución y está abierto a comentarios y aportes que ayuden a mejorar su funcionalidad y diseño.

### 🇺🇸 English
This project is a game inspired by a fun anecdote shared with friends, particularly with *Astorias*, who inspired the idea. It features a jumping pig and serves as a practical exercise to strengthen software development skills.  
The project is continuously evolving and welcomes feedback and contributions to improve both functionality and design.
